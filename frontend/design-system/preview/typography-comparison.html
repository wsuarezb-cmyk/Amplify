Opción A — Mi recomendación
Syne para display/headlines + Inter para UI. Más carácter, más dinámico. Las métricas grandes se leen como datos importantes, no solo texto. Contrasta bien con el verde corporativo. Buena elección si quieren que el dashboard se sienta moderno y diferenciado dentro del ecosistema Falabella.
Opción B — También sólida
Plus Jakarta Sans como sistema único. Más cerca del estilo iOS/Apple. Muy legible en tablas y formularios, menos distracción visual. Ideal si el foco es claridad funcional sobre personalidad. Más fácil de implementar (una sola familia). Más "safe" para enterprise B2B.
